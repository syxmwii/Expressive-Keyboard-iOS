# Expressive Keyboard для iOS

Нативное приложение настроек на SwiftUI и системное расширение клавиатуры на UIKit для iPhone и iPad. Порт основан на [Expressive Keyboard для Android](https://github.com/kotlalipopus/Expressive-Keyboard/tree/727393aaf3526eb259ffbb7753634bbd5ce7a2b8).

## Запуск на iPhone

1. Скачайте IPA из Releases и подпишите приложение **вместе с расширением**. В установщике выберите Keep App Extensions. Идентификатор расширения должен начинаться с идентификатора подписанного приложения и точки, оба компонента подписываются одной командой. App Groups для этой сборки не требуются.
2. При запуске из Xcode выберите свою команду для обеих целей и задайте уникальный EXPRESSIVE_BUNDLE_ID в Build Settings проекта.
3. На iPhone откройте Настройки → Основные → Клавиатура → Клавиатуры → Новые клавиатуры → Expressive Keyboard. В обычном текстовом поле удерживайте глобус и выберите клавиатуру.
4. Тему, языки, ряд цифр и автоисправление можно менять прямо в меню ⚙ → Быстрые настройки. Для переноса всех настроек, включая фото и шрифт, нажмите в приложении «Скопировать настройки для клавиатуры», затем в клавиатуре ⚙ → «Применить настройки из приложения». Для этого переноса через буфер включите полный доступ. Пакет настроек доступен в буфере пять минут.
 
Для проверки сборки в симуляторе из терминала на Mac:

```sh
xcodebuild -project ExpressiveKeyboard.xcodeproj -scheme ExpressiveKeyboard \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

## Перенесённые функции

| Раздел | Возможности в iOS-проекте |
|---|---|
| Ввод | 205 исходных раскладок, редактирование рядов, варианты клавиш, регистр, цифры, символы и перемещение курсора свайпом по пробелу |
| Языки | Pinyin с упрощённым и традиционным словарями, Romaji → Kana с кандидатами Kanji, хангыль 2-beolsik, Telex, эфиопский ввод и перестановка знаков мьянманского письма |
| Подсказки | Локальные словари EN, RU и AM, частотные подсказки, таблицы опечаток EN/RU, системный словарь iOS, обучение и ввод свайпом по встроенным словарям |
| Оформление | Девять пресетов, три степени фигур, цвет акцента, фото, TTF/OTF, форма клавиш, размеры, режим для одной руки, звук и тактильный отклик |
| Эмодзи | Каталог Unicode 16 из исходного проекта, категории, поиск на русском и английском, недавние, тона кожи и варианты спрайтов Twemoji, Noto, Blob, OpenMoji |
| Инструменты | Буфер с ручным добавлением и закреплением, перевод через Google Translate для явно выбранного текста, GIF-ссылки и копирование GIF в буфер, экспорт настроек |
| Диктовка | Запись и распознавание в приложении Expressive Keyboard, копирование расшифровки и вставка из панели клавиатуры через буфер |
| Плагины | Импорт JSON, JS и ZIP с `plugin.json` и `main.js`, действия, сокращения, символы, оформление и раскладки, JS-панели и события через QuickJS |

В **Настройки → Ввод** можно установить свой ключ GIPHY. Без ключа доступны заранее заданные ссылки. Перевод отправляет выбранную фразу в Google Translate только после нажатия кнопки. Инкогнито приостанавливает обучение, историю буфера, моды и сетевые панели.

## Совместимость и проверка

- iOS показывает системную клавиатуру в защищённых полях и некоторых полях телефонного ввода. Расширение работает через текстовый интерфейс iOS. Вставка GIF как медиа происходит через буфер в приложениях, которые это поддерживают. [Apple Developer](https://developer.apple.com/design/human-interface-guidelines/virtual-keyboards)
- Совместимость с Android API плагинов частичная. Поддерживаются основные действия ввода, события, виджеты панели, локальное хранилище и рисование. Android-расширения для шейдеров, датчиков, аудио и доступа к приложениям, сетевые вызовы модов и дополнительные файлы из ZIP требуют отдельной адаптации. Документ `PLUGINS-Android.md` описывает исходное API.
- В Linux выполнены проверки раскладок, составного ввода, словарей, импорта ZIP, структуры проекта и QuickJS. Сборку с Apple SDK, отзывчивость клавиш, подсказки в сторонних приложениях, медиа и диктовку следует проверить на Mac и iPhone.
