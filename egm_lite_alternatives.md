# Alternatives Considered — исправления iOS-порта

> **BLUF:** Рекомендую вариант A: закрыть найденные дефекты (плагины, жесты, буфер, настройки), не переписывая архитектуру. Вариант B добавляет устойчивость и кэширование только там, где дефект уже подтверждён кодом; вариант C — отдельная задача на паритет с upstream, а не «улучшение» текущего порта.

## A. Точечные исправления подтверждённых дефектов (рекомендуется)

- События касаний не гейтить правом `read_text` — иначе рисование в `studio.js` никогда не получает точки.
- Не «отравлять» runtime навсегда после первого исключения в плагине.
- Добавить no-op заглушку `kb.tone`, чтобы `studio.js` не падал на пианино.
- `cut` через выделение, а не `erase(1)`; `home`/`end` в UTF-16.
- Автозаглавные для `.asciiCapable`.
- Сброс статусной строки с учётом обрезки до 120 символов.
- Осознанно решить судьбу `Group.entitlements` (подключить `CODE_SIGN_ENTITLEMENTS` или удалить файлы вместе с capability).

Дифф оценочно 8 файлов, ~120 строк. Риск низкий, каждый пункт проверяем чтением кода и существующими тестами.

## B. A + устойчивость и горячий путь

- Терпимое декодирование `Preferences` (`decodeIfPresent`), чтобы добавление поля не сбрасывало все настройки.
- Кэш разобранного манифеста плагина (`Plugin.object` парсит JSON на каждый вызов хоста) и кэш скина (`KeyboardTheme` читает файл с диска на каждый `redraw`).
- Инвалидация кадрового таймера при уходе в инкогнито.

Дифф ~250 строк, затрагивает `Shared/Settings.swift` и `Shared/Plugin.swift`. Выгода реальная, но это уже рефакторинг сериализации; риск сломать совместимость бэкапов нужно закрывать тестом.

## C. Паритет с upstream 11.2.9

Графика, видео-фоны, новые плагины и разделы настроек из трёх релизов после закреплённого коммита `727393a`. Это новая функциональность, а не исправление ошибок: требует отдельного плана и дизайна, в текущий цикл не входит.

## Ограничения проверки

- Swift/UIKit собрать и запустить на этой машине нельзя: выводы по рантайм-поведению клавиатуры и жестов — из чтения кода, не из запуска. `[⏳ ACK]` на iOS-специфику (self-sizing, одновременные распознаватели, буфер при полном доступе).
- Тест QuickJS собран и пройден локально (`gcc`, `Runtime/*.c` + `Tests/QuickJSChecks.c`), это единственная исполненная проверка.
